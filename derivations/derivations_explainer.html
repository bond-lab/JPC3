Background

Czech derives a feminine personal noun from a masculine one with a handful of suffixes — učitel → učitelka "teacher", přítel → přítelkyně "friend", lev → lvice "lion → lioness". This is přechylování (motion), and project 2 adds these derivational relations to the wordnet.

The serious candidate source is DeriNet, which already encodes Czech word-formation families. Before wiring that in, this script shows the shape of the problem with the crudest possible heuristic: if a lemma plus a feminine suffix is also a lemma, propose the pair.

It over-generates on purpose. A string match cannot tell derivation from coincidence. That is the point: the candidate list is nearly free, so the deliverable is how well you can tell the real pairs from the false friends — the validation, not the list.

Intuition

Take every noun lemma in the Czech wordnet. For each, try appending each suffix; if the result is itself a lemma, report the pair. Then look at what comes out of a real run:

Two of the first six are wrong, and wrong in different ways — a coincidental suffix, a diminutive. Those are the error types your taxonomy will name and count.

This is a first example, not the method. Once you have judged a sample, refine the code to match what you found: restrict bases to person synsets (project 1's role-noun list is ready-made), drop diminutives like -ka on inanimates, or swap the heuristic for DeriNet's families. 2 · candidates()

feminine_candidates.py:27–33

Collect the set of all noun lemmas once, then for each lemma and each suffix test membership. Yielding tuples keeps it lazy, so a limit stops early.

lemmas = {w.lemma() for w in cs.words(pos="n")}
for base in sorted(lemmas):
    for suf in SUFFIXES:
        if base + suf in lemmas:
            yield base, base + suf, suf
