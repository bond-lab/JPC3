Background

Some synsets will never have a drawn pictogram and do not need one. Colour terms are the clear case. ARASAAC has a handful: black is pictogram 2886, tagged with synset 00393873-a and with the Czech keywords černá, černý, černé, černá barva; red is 2808, tagged 00382159-s. The English wordnet has far more. 146 colour adjectives hang off chromatic (00366691-a): beige, chestnut, khaki, maroon, teal, lavender, amber, auburn, avocado, canary, caramel, carnation, and on. 46 hang off achromatic (00386392-a): grey, charcoal, ebony, jet-black, chalky. And 139 colour nouns sit under color (04956594-n): blackness, scarlet, ochre, bottle green, navy blue, sepia, brick red.

The Czech wordnet (ntumc-cs:2026.08) has lemmas for only a few of them so far: 11 of the 146 chromatic adjectives (červený, modrý, zelený, žlutý, hnědý, růžový, zlatý, bronzový, rezavý, krémový, and růžový again for rose), 6 of the 46 achromatic ones (šedý, stříbrný, popelavý, smolný, eben, inkoustová čerň), and 34 of the 139 nouns (čerň, červeň, žluť, zeleň, modř, hněď, šeď, námořnická modř, cihlová červeň, sépie, …). Chestnut (00373209-s), maroon and teal have no Czech lemma yet. Each of these, and each colour synset a student adds, wants a pictogram that looks like ARASAAC's.

Look at how ARASAAC draws a colour and the solution is obvious. Its colour pictograms are a single flat colour on a transparent background — a paint-splash silhouette, nothing else. So a pictogram for any colour can be generated in exactly that style: keep the silhouette and refill it with the colour's hex value, taken from the xkcd colour survey, which matplotlib ships offline as XKCD_COLORS: 949 names, every key prefixed xkcd:, every name lower-case, no two sharing a hex value. They are what survey respondents typed, so they run from the plain to the odd:

Crowd-sourced spelling shows. Both burnt siena #b75203 and burnt sienna #b04e0f are in, with different values; so are ocher #bf9b0c and ochre #bf9005. vermillion is in, vermilion (the wordnet's spelling) is not. grey appears in 47 names, gray in none.

The lookup is exact after lower-casing, so chestnut, Chestnut and "Burnt Orange" all work, and each of these is rejected with … is not an xkcd colour name and exit status 1: "chestnut brown", chesnut, gray, vermilion, "jet black", burnt-orange (a hyphen), "burnt orange" (two spaces), and xkcd:chestnut (the script adds the prefix itself, so this doubles it).

Across the data: 51 of the 146 chromatic adjectives have an xkcd-named lemma; of the 11 with Czech lemmas, 10 do (all but krémový creamy). Of the 34 colour nouns with Czech lemmas, 27 do. Where a synset has several matching lemmas, as navy and sepia do, someone has to pick the hex.

Noun and adjective. ARASAAC links its colour pictograms to the adjective synsets and tags them with WordNet 3.1 ids. 00393873-a maps through CILI to i2222, which in the 3.0-numbered omw-en:2.0 used here is 00392812-a black, Czech černý; the noun black, blackness is 04960277-n, Czech čerň. One image serves both. Link the adjective first, as ARASAAC does, and the noun after.

A trap on the way. ARASAAC's red tag 00382159-s maps to i2130, which is 00381097-s red, reddish, ruddy. The Czech synset at that offset, ntumc-cs-00381097-a rudý, červený, krvavý, exists but carries no ILI (only 918 of the 2,251 Czech adjective synsets do), so the ILI route in arasaac_to_czech.py prints MISSING for it. Matching on the offset finds it.

Licence. A recoloured pictogram is a derivative of ARASAAC's, so it inherits CC BY-NC-SA 4.0: credit ARASAAC and keep the licence. Say in the data statement that the image is generated.

Intuition

Four steps; the only real work is one line of Pillow.

The template in numbers

arasaac_2886_black.png is a palette-mode PNG (P: 19 palette entries plus a transparency table). Converted to RGBA it is 250,000 pixels, in three kinds:

AlphaPixelsShareWhat they are
0162,75765.1 % background; their RGB is (71, 112, 76), a greenish grey nobody ever sees
25584,86033.9 % the splash; every one is (0, 0, 0)
1–2542,3831.0 % the anti-aliased edge: 17 values such as 250, 240, 226, 22, 8

The splash's bounding box runs from (26, 59) to (474, 462). Three pixels, before and after uv run colour_swatch.py chestnut:

PixelTemplate RGBAchestnut.png RGBA
(0, 0), a corner(71, 112, 76, 0)(116, 40, 2, 0)
(250, 250), the centre(0, 0, 0, 255)(116, 40, 2, 255)
(411, 59), the first edge pixel(0, 0, 0, 8)(116, 40, 2, 8)

Every output pixel has RGB (116, 40, 2), and the output's alpha channel is byte-for-byte the template's: 19 distinct RGBA values in, 19 out.

The key idea: the shape is the alpha mask. Every pixel keeps its transparency and only its colour changes, so the anti-aliased edges stay smooth and the splash looks hand-drawn, because it was. The fill is never read, so starting from ARASAAC's red (2808) would work the same way — though its file is not a pixel-for-pixel twin: the same splash, filled (225, 18, 6), has 66,033 opaque pixels and 21,412 partly transparent ones against black's 84,860 and 2,383, a much softer edge. An unknown colour name returns None rather than a blank image, so the caller can tell "no such colour" from "done".

3 · recolour()

colour_swatch.py:43–52

Look the name up (lower-cased, with the xkcd: prefix matplotlib uses) and bail out with None if unknown. Otherwise make a solid image of the target colour the same size as the template and give it the template's alpha channel — that single putalpha is the whole trick.

hexv = XKCD_COLORS.get(f"xkcd:{name.lower()}")
...
src = template()
out = Image.new("RGBA", src.size, ImageColor.getrgb(hexv) + (0,))
out.putalpha(src.getchannel("A"))                 # the shape is the alpha mask
out.save(path)

The lookup key, and what the dictionary returns, for four real names:

namekey looked uphexvresult
"chestnut"xkcd:chestnut#742802yes image written
"Burnt Orange"xkcd:burnt orange#c04e01yes the lower() did it
"chestnut brown"xkcd:chestnut brownNoneno returns None, nothing written
"xkcd:chestnut"xkcd:xkcd:chestnutNoneno the prefix is doubled

Then, for chestnut: ImageColor.getrgb("#742802") is (116, 40, 2), and + (0,) makes it (116, 40, 2, 0), so out starts as 250,000 fully transparent chestnut pixels. src.getchannel("A") is a 500 × 500 single-band (L) image with extrema (0, 255); after putalpha the output has the template's 162,757 / 84,860 / 2,383 split exactly. The function returns "#742802".
