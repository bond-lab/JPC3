Background

Some synsets will never have a drawn pictogram and do not need one. Colour terms are the clear case: ARASAAC has a handful — black is pictogram 2886, red is 2808 — but the wordnet has far more: kaštanová "chestnut", spálená oranžová "burnt orange", and on.

Look at how ARASAAC draws a colour and the solution is obvious. Its colour pictograms are a single flat colour on a transparent background — a paint-splash silhouette, nothing else. So a pictogram for any colour can be generated in exactly that style: keep the silhouette and refill it with the colour's hex value, taken from the xkcd colour survey (949 named colours, shipped offline in matplotlib). The result sits in the same visual family as the real pictograms it will be matched alongside — which matters for an AAC user whose board should look consistent.

Noun and adjective. ARASAAC links its colour pictograms to the adjective synsets (black is 00393873-a); the wordnet also has each colour as a noun. One image serves both. Link the adjective first, as ARASAAC does, and the noun after.

Licence. A recoloured pictogram is a derivative of ARASAAC's, so it inherits CC BY-NC-SA 4.0: credit ARASAAC and keep the licence. Say in the data statement that the image is generated.

Intuition

Four steps; the only real work is one line of Pillow.

StepExample
fetch the template onceARASAAC 2886 "black", a 500 px PNG, cached beside the script
name → hexXKCD_COLORS["xkcd:chestnut"] → #742802
refill the silhouettenew image of solid #742802, with the template's alpha channel pasted on
savechestnut.png; likewise #c04e01 for "burnt orange"

The key idea: the shape is the alpha mask. Every pixel keeps its transparency and only its colour changes, so the anti-aliased edges stay smooth and the splash looks hand-drawn, because it was. Since the template is one flat colour, it makes no difference whether you start from black or red — only the mask is used. An unknown colour name returns None rather than a blank image, so the caller can tell "no such colour" from "done".

3 · recolour()

Look the name up (lower-cased, with the xkcd: prefix matplotlib uses) and bail out with None if unknown. Otherwise make a solid image of the target colour the same size as the template and give it the template's alpha channel — that single putalpha is the whole trick.

hexv = XKCD_COLORS.get(f"xkcd:{name.lower()}")
...
src = template()
out = Image.new("RGBA", src.size, ImageColor.getrgb(hexv) + (0,))
out.putalpha(src.getchannel("A"))                 # the shape is the alpha mask
out.save(path)
