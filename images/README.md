# Project 4 — ARASAAC & Global Symbols pictographs

Extend [ARAWN](https://github.com/omwn/arawn) (the existing ARASAAC wordnet):
add colour variants, match more synsets, and bring in sets from other countries
(e.g. the Bulgarian and Croatian sets on
[Global Symbols](https://globalsymbols.com/)). Watch the per-set licences — they
differ — and report them.

The pictograms, tags and Czech lemmas in v1 were pulled on 2026-11-04 from the
ARASAAC API, the CILI table and `ntumc-cs:2026.08` (ARASAAC's data changes, so a
search may return different pictograms later). To see them, or find your own,
run this beside the script after `arasaac_to_czech.py` has fetched
`ili-map-pwn31.tab`:

```python
# /// script
# dependencies = ["wn>=1.1", "requests"]
# ///
import requests, wn
wn.config.data_directory = "../patterns/.wn_data"
en = wn.Wordnet(lexicon="omw-en:2.0")
cs = wn.Wordnet(lexicon="ntumc-cs:2026.08")
ili = {}                                          # 3.1 offset -> ILI
for line in open("ili-map-pwn31.tab", encoding="utf-8"):
    i, off = line.split("\t", 1); ili[off.strip()] = i
url = "https://api.arasaac.org/api/pictograms/cs/search/kočka"
for p in requests.get(url, headers={"accept": "application/json"}).json():
    print(p["_id"], [k["keyword"] for k in p["keywords"]], p["synsets"] or "no synsets")
    for off in p["synsets"]:                     # English side shows what MISSING means
        e = en.synsets(ili=ili[off])[0]; c = cs.synsets(ili=ili[off])
        print("  ", off, ili[off], e.lemmas(), "->", [w.lemma() for s in c for w in s.words()] or "MISSING")
```

from matplotlib.colors import XKCD_COLORS

## Both sources have usable public APIs

**ARASAAC** pictograms already carry a WordNet synset tag (a 3.1 offset) and a
`sex` flag, so they bridge to Czech by exactly the ILI route projects 3 and 5
use:

The bridge is in [`arasaac_to_czech.py`](arasaac_to_czech.py):

```bash
uv run arasaac_to_czech.py pes 5     # pictogram id, offset, ILI, Czech lemmas, image URL
```

(`reversed(line.split(...))` flips each `ili<TAB>offset` row into
`offset -> ili`; strip whitespace if you keep the values.)

**Global Symbols** returns an image URL and the symbol-set it came from:

```
GET https://globalsymbols.com/api/v1/symbolsets                      # list sets + licences
GET https://globalsymbols.com/api/v1/labels/search?query=dog&language=eng&symbolset=<id>
# -> [{ picto: { image_url, symbolset_id, part_of_speech, native_format }}]
```

The Bulgarian/Croatian sets are particular `symbolset` ids — list the sets
first and note each one's licence before you import its images.

## Generate what you can't find: colour pictograms

Some synsets will never have a drawn pictograph — and don't need one. **Colour
terms** are the clear case: ARASAAC has a handful (*black* is pictogram 2886,
*red* 2808), but the wordnet has far more (*chestnut*, *burnt orange*, *dark
teal*, …). ARASAAC's colour pictograms are a single flat colour on a transparent
background — a paint-splash silhouette — so a new one can be *generated* in the
same style: keep the silhouette and refill it with the colour's hex value from
the xkcd colour survey (949 named colours, shipped offline in matplotlib).

The generator is [`colour_swatch.py`](colour_swatch.py); it downloads the black
template once and caches it beside itself:

```bash
uv run colour_swatch.py chestnut             # -> chestnut.png  (#742802)
uv run colour_swatch.py "burnt orange" out.png
```

Match an xkcd name to the English colour lemma, bridge to the Czech synset by the
same ILI route as the other projects, and attach the generated image. Note that
ARASAAC links its colour pictograms to the **adjective** synsets (black is
`00393873-a`); the wordnet also has each colour as a **noun**. One image serves
both — link the adjective first, as ARASAAC does, and the noun after.

Caveats for the report: say the image is **generated** from ARASAAC's template
(a data statement), and that it inherits ARASAAC's licence — CC BY-NC-SA 4.0, so
credit ARASAAC and keep the licence; xkcd names are crowd-sourced English, so
the Czech match needs checking.

## Angles for the four-part spine

- **Match more synsets.** ARASAAC's own synset tags are a starting alignment;
  for untagged pictographs match on the Czech/English keyword through the
  wordnet. Report a coverage before/after over the synset inventory (weight by
  frequency if you can).
- **Colour variants.** ARASAAC serves colour and plain versions (and skin/hair
  options) of the same pictogram id — a clean before/after figure.
- **Error analysis.** Hand-check 100 matches: is the picture a fair depiction of
  *that sense*? Group the failures (wrong sense, too abstract, culture-specific).
- **Licences.** One short table: symbol set → licence → count imported.
