JPC3 · Palacký University, Olomouc

Improving the Czech Wordnet

A project course: small, careful contributions to the Czech wordnet and the Open Multilingual Wordnet. The emphasis is on validation — error analysis, inter-annotator agreement, and giving fixes back upstream.

Code, data, and project briefs: github.com/bond-lab/JPC3

The projects

  • 1 · Patterns (přechylování) — feminine / motion variants
  • 2 · Derivations — derivational and morphosemantic relations
  • 3 · Sensebank — remap the PDT 1.5 sense tags to current synsets
  • 4 · Images — ARASAAC & Global Symbols pictographs for AAC
  • 5 · Wikidata — Wikidata → ILI → Czech candidate links
  • 6 · LLM — LLM-assisted quality estimation, grounded in Wikidata

Each has a brief, starter code, and a README in the repository.
