Background

Between 2004 and 2011, ÚFAL in Prague tagged words of the Prague Dependency Treebank (PDT) with synsets of the Czech WordNet. The work is spread over three datasets on LINDAT, all CC BY-NC-SA 3.0, and the loader needs all three:

KeyDatasetWhat the loader takes from it
cwnCzech WordNet 1.9 PDT the 23,094 synsets the annotators chose from (nas_anotacni_slovnik.xml, "our annotation dictionary")
annLexico-Semantic Annotation of PDT 1,814 stand-off files, one tag per annotated word, 148,865 words in all
pdtPDT 3.0 only the morphological layer: each word's form, lemma and tag, and its sentence (128 MB zip)

The annotation is stand-off: a tag does not contain the word. It points at a word in PDT by id, such as m-cmpr9406-054-p3s1w2 (document cmpr9406_054, paragraph 3, sentence 1, word 2). To know which word was tagged, you have to open PDT too.

A tag is one of four things:

  • a Princeton WordNet 1.5 offset, usually without its leading zeros or part of speech: 1307561 is synset 01307561-v, mít "have, own"; 429214 is 00429214-a, velký "big";
  • the id of a synset added to this copy with no Princeton counterpart: NAS-430683854 (mít "have to", added by ÚFAL in 2006), 1448862335 (panáčkování);
  • a small number, one of the exceptions the annotators could choose instead of a synset: 1, 7, 4;
  • a hyphen, -: no agreed tag.

The codes are not documented. The papers list the exceptions in order but never say which number is which. The meanings in EXCEPTIONS were inferred from the data, and two of them are guesses.

Each word passes through three files. The tag file says which word and which tag; the annotation wordnet says what the tag means; PDT says what the word is.

2 · The exception codes

pdt_sources.py:43–61

The comment says how each meaning was found. Code 4 is the clearest test: PDT lemmatises a negated word to its positive form, so a word whose sense the wordnet has only in the positive should be negated, and 99.7% of code-4 words are. Codes 5 to 7 were read off their commonest lemmas, 8 and 10 match the counts in Bejček et al. (2006), and 0 and 1 are guesses.

EXCEPTIONS = {
    "0": "other problem (guess)",
    "1": "missing sense (guess)",
    "2": "incorrect reflexivity",
    ...
    "10": "missing more general sense",
}
UNTAGGED = "-"

3 · Reading the annotation wordnet

pdt_sources.py:126–163

The XML is ISO-8859-2 and has no root element, just one <SYNSET> after another, so read_nas() strips the declaration and wraps the body in <wn> before parsing. literal() drops homonym marks: 'vypadat ^2' becomes vypadat.

body = re.sub(r"^<\?xml[^>]*\?>", "", raw)
root = ET.fromstring(f"<wn>{body}</wn>")

Each synset becomes a NasSynset. Two real ones:

01307561-v  mít  "vlastnit, získat"  e.g. "Mám spoustu peněz."  hypernym 01286642-v
            stamp "bejce9am 2006/03/14"  pwn15 -> 01307561-v
NAS-430683854  mít  "mít povinnost"  e.g. "Mám připravit večeři? [z Vallexu]"
            stamp "bejce9am 2006/03/14"  pwn15 -> None
pdt_sources.py:64–84 (NasSynset, pwn15)

The pwn15 property returns the 1.5 offset for an id like 01307561-v, writing adverbs (b in the file) as r, and None for a synset with no Princeton id.

4 · From a tag to a synset id

pdt_sources.py:166–183

Tags drop the zeros and the part of speech, so tag_index() builds the reverse map: 1307561 → 01307561-v. Ids with no Princeton offset map to themselves.

index.setdefault(sid.split("-")[0].lstrip("0") if sid[0].isdigit() and "-" in sid
                 else sid, sid)

Dropping the part of speech loses information: 9 numbers name a synset in two parts of speech, and setdefault keeps the first one in the file.

5 · Normalising a tag

pdt_sources.py:186–199

Most tags drop the offset's zeros, but a few keep them, so a lookup of the raw tag misses. tag_key() strips the zeros from any tag that looks like an offset, and leaves exception codes and ids of new synsets alone.

return tag.lstrip("0") if tag.isdigit() and len(tag) > 2 else tag
00600945       -> 600945       -> 00600945-v  poskytnout, dát, dávat, udělit
00604079       -> 604079       -> 00604079-v  zavést, představit, uvést, uvádět
1307561        -> 1307561      -> 01307561-v  mít
0              -> 0            (exception code, unchanged)
NAS-450034833  -> NAS-450034833 -> NAS-450034833  moci

Four zero-padded tags occur, on 55 words; before tag_key() they reached no synset. The len(tag) > 2 test protects the exception codes: without it, "0" would become the empty string.

6 · From a synset to an ILI

pdt_sources.py:202–231

pwn15_ili() reads the CILI table ili-map-pwn15.tab (90,030 entries), keeping the third column, the confidence of each link. ili_of() looks up an annotation synset's offset, and retries an adjective as a satellite (-s), since 1.5 may file it that way.

01307561-v  -> ('i33221', 1.0)    mít "have"
00003711-n  -> ('i35560', 1.0)    buňka "cell"
01781692-a  -> ('i9930', 0.228)   dobrý "good", a doubtful link
NAS-430683854 -> None

The confidence matters downstream. The 0.228 link for dobrý leads to výborný "excellent", which is wrong, so the other scripts use only links of confidence 1.

7 · Reading the tags, then joining PDT

pdt_sources.py:234–267

read_tags() walks the .s files in sorted order and yields one Token per <st>, with the document, the m-id and the tag. read_tokens() wraps it: when the document changes, it opens that document's .m.gz file inside the PDT zip (without unpacking the 128 MB archive) and fills in the lemma, the morphological tag, the form and the sentence.

if tok.doc != doc:
    doc = tok.doc
    morph = read_morph(pdt.read(mfiles[doc])) if doc in mfiles else {}
if tok.mid in morph:
    tok.lemma, tok.mtag, tok.form, words, i = morph[tok.mid]
    tok.sentence = detokenise([*words[:i], f"«{tok.form}»", *words[i + 1:]])

Reading one document at a time keeps memory small, and works because the tags come in document order. Two annotated documents are missing from PDT 3.0; their three words come back with an empty lemma.

8 · Sentences and lemmas

pdt_sources.py:270–313

read_morph() maps every m-id in a document to its lemma, tag, form, the forms of its sentence, and its position. detokenise() joins tokens without a space before punctuation: ["Ahoj", ",", "světe", "(", "a", ")", "."] becomes Ahoj, světe (a).

base_lemma() strips PDT's technical suffixes, so the lemma can be compared with wordnet lemmas:

stát-2_^(státní_útvar)  -> stát
vycházet_:T             -> vycházet
Praha_;G                -> Praha
e-mail                  -> e-mail

The last line is why the pattern removes -2 only at the end, and only when something comes before it: the hyphen in e-mail stays.

Glossary

stand-off annotationtags kept in separate files that point at the words by id, instead of being written into the text.
m-layerPDT's morphological layer: each word's form, lemma and morphological tag (VB-S---3P-AA---).
offseta Princeton WordNet synset id such as 01307561-v; it changes between WordNet versions.
ILIan Interlingual Index id such as i33221, one per concept across wordnets; the stable key.
CILIthe Collaborative Interlingual Index, which keeps maps from old WordNet versions to ILIs.
exceptiona code an annotator chose when no synset fitted: a proper name, a missing sense, a wrong lemma.
