Background

Czech derives a feminine personal noun from a masculine one with a handful of suffixes — učitel → učitelka "teacher", přítel → přítelkyně "friend", lev → lvice "lion → lioness". This is přechylování (motion), and project 2 adds these derivational relations to the wordnet.

The Czech wordnet (ntumc-cs:2026.08) already holds some of each kind. učitel, učitelka sit together in the teacher synset 10694258-n; soused, sousedka share neighbor; dělník, dělnice, proletář share proletarian. Others are split the way English splits them: herec is in actor (09765278-n) and herečka alone in actress (09767700-n); žák in schoolboy, žákyně in schoolgirl. And many are simply missing: lékař "doctor", lev "lion" and student are lemmas, but lékařka, lvice and studentka are not in the wordnet at all.

The four suffixes the script tries, with the lemmas that actually end in them (of the 25,093 noun lemmas; 10,045 of those are multi-word, like zdravotní sestra):

SuffixLemmas ending in itFeminines among themNot feminines
-ka1,707 učitelka, kuchařka, sousedka, manželka, Evropanka Afrika, Amerika, matka "mother", kočka "cat", ruka "hand", otázka "question"
-kyně5 přítelkyně, obchodní zástupkyně, žákyně jeskyně "cave"
-ice392 dělnice "working woman" abolice, Hromnice, krabice "box", stanice "station", Celsiova stupnice
-yně13 bohyně "goddess", hospodyně "housewife" kuchyně "kitchen", mochyně "physalis"

So most -ka and -ice words are not feminines at all; the ending alone proves nothing. The script therefore asks a second question: is the string before the suffix also a lemma? kočka is dropped (no lemma koč) and Afrika is dropped (no Afri) — but matka survives, because mat "checkmate" is a lemma.

The serious candidate source is DeriNet, which already encodes Czech word-formation families. Before wiring that in, this script shows the shape of the problem with the crudest possible heuristic: if a lemma plus a feminine suffix is also a lemma, propose the pair.

It over-generates on purpose. A string match cannot tell derivation from coincidence. That is the point: the candidate list is nearly free, so the deliverable is how well you can tell the real pairs from the false friends — the validation, not the list.

Intuition

Take every noun lemma in the Czech wordnet. For each, try appending each suffix; if the result is itself a lemma, report the pair. Two more things the data shows. First, sharing a synset is neither necessary nor sufficient: 20 of the 112 pairs share a synset, but nine of those are diminutives or synonyms (brožka, hůlka, hrobka, pastelka, směsice, součástka, sušička, vysílačka, čtvrtka), while three real feminines share none (ředitelka is only in principal, přítelkyně only in girlfriend, žákyně only in schoolgirl) because English keeps those apart. Second, the heuristic misses pairs that are right there whenever the base changes form: herec → herečka (c → č), dělník → dělnice (the -ík goes), bůh → bohyně (ů → o), král → královna (a suffix not on the list). All eight lemmas are in the wordnet; none appears in the output.

This is a first example, not the method. Once you have judged a sample, refine the code to match what you found: restrict bases to person synsets (project 1's role-noun list is ready-made), drop diminutives like -ka on inanimates, or swap the heuristic for DeriNet's families. Expect the next version of feminine_candidates.py to look different — then re-judge the same sample and see whether precision went up.

Code

Three parts, in the order they run.

1 · Share the database, name the suffixes

feminine_candidates.py:23–24

Reuse the wn database the other projects built under patterns/.wn_data, and list the suffixes to try.

SUFFIXES = ("ka", "kyně", "ice", "yně")

The tuple is tried in this order for every base, so a base can fire more than once: kost "bone" yields both kostka "cube" and kostice "whalebone", one line each. Note what is not on the list: -ovna (král → královna), and no stem alternation at all: herečka is -ka after c → č, dělnice is -ice after dropping -ík, so neither is ever proposed even though both are lemmas.

2 · candidates()

feminine_candidates.py:27–33

Collect the set of all noun lemmas once, then for each lemma and each suffix test membership. Yielding tuples keeps it lazy, so a limit stops early.

lemmas = {w.lemma() for w in cs.words(pos="n")}
for base in sorted(lemmas):
    for suf in SUFFIXES:
        if base + suf in lemmas:
            yield base, base + suf, suf

cs.words(pos="n") returns 25,093 word entries, and the set has 25,093 distinct lemmas — one entry per lemma in this lexicon. For the base učitel the inner loop tests four strings:

"učitel" + "ka"   = "učitelka"    in lemmas  -> yield ("učitel", "učitelka", "ka")
"učitel" + "kyně" = "učitelkyně"  not a lemma
"učitel" + "ice"  = "učitelice"   not a lemma
"učitel" + "yně"  = "učitelyně"   not a lemma

For lékař all four fail (lékařka is not in the wordnet), so a genuine derivation goes unproposed; for sto "hundred" the first test succeeds on stoka "sewer", so a coincidence is proposed. The function knows nothing about meaning — only string membership. sorted(lemmas) explains the first line of every run: Python sorts capitals before lower case, so Evropan precedes adresát.
