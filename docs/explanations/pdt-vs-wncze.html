Background

Between 2004 and 2011, ÚFAL in Prague tagged words of the Prague Dependency Treebank with synsets of their own copy of the Czech WordNet, released on LINDAT as Czech WordNet 1.9 PDT (23,094 synsets). The tags themselves are a separate LINDAT record. While they annotated, they edited that copy: Bejček et al. (2006) describe rewriting the senses of the 25 most-disputed lemmas, such as mít "have", moci "can" and cena "price", each with a definition and an example.

Meanwhile the main line of the wordnet went on in Brno, and is now the open Czech WordNet release 2.2 (lexicon wncze:2.2). The script asks what of the PDT copy is in the release today.

The two copies number their synsets differently. The PDT copy uses WordNet 1.5 offsets (01307561-v is mít); the release uses WordNet 2.0 offsets (wncze-02231793-v is mít). So the script never compares ids. It goes through the Collaborative Interlingual Index (CILI), whose ili-map-pwn15.tab maps each 1.5 offset to an ILI, with a confidence between 0 and 1. The release carries ILIs, so the ILI names the release synset.

Why not compare ids? The script tests that too (id_check). Read as 2.0 ids, 33 of the 22,930 PDT offsets name a synset in the release, and none of those 33 shares a single word with it.

Who edited a PDT synset is written in its edit stamp. Stamps starting bejce are Eduard Bejček's at ÚFAL (bejce9am, bejcek; 203 synsets, all in 2006). The rest are the Brno team's (3,133 synsets, from users such as xcapek1, pala, ybara and ydita, 2001 to 2006).

2 · load_wncze()

pdt_wordnet_vs_wncze.py:91–104

Load wncze:2.2 (downloading it once) and build the two lookups the rest needs: the release synset for each ILI, and the synsets each lemma is in, by part of speech. pos() folds the PDT copy's b (adverb) and satellites to n v a r.

cs = wn.Wordnet(lexicon=CES)
by_lemma: dict[tuple[str, str], set[str]] = defaultdict(set)
for sense in cs.senses():
    ss = sense.synset()
    by_lemma[(sense.word().lemma(), pos(ss.pos))].add(ss.id)
return Wncze({ss.ili: ss for ss in cs.synsets() if ss.ili}, by_lemma)

3 · classify()

pdt_wordnet_vs_wncze.py:148–183

The heart of the script: one PDT synset in, one Row out. A new synset (no Princeton id) is looked up by its words: the release synsets that hold every one of them. Otherwise the 1.5 offset goes to an ILI, the ILI to a release synset, and the words are compared.

words = {w.lemma() for w in ss.words()}
kept = sum(1 for w in syn.literals if w in words)
if kept == len(syn.literals):
    status = "all words kept"
elif kept:
    status = "some words kept"
elif any((w, p) in cs.by_lemma for w in syn.literals):
    status = "no word kept, words elsewhere"
else:
    status = "no word kept, words gone"

"Elsewhere" means the word is in the release, in some other synset of the same part of speech: a sign of a moved word or a wrong link, as with dobrý. "Gone" means the release has no such word at all.

4 · norm() and carried(): definitions and examples

pdt_wordnet_vs_wncze.py:119–145

The PDT copy often starts a definition with its lemma (fax: zpráva přenesená zařízením Fax-1). norm() drops that prefix, quotes and final punctuation, and lower-cases, giving zpráva přenesená zařízením fax-1. carried() then counts a PDT text as carried if its normalised form is in, or inside, one of the release synset's.

targets = [norm(t) for t in into]
return sum(1 for t in texts if norm(t) and any(norm(t) in x for x in targets))

5 · hypernyms_kept()

pdt_wordnet_vs_wncze.py:186–209

For each PDT hypernym link whose two ends both reached the release, is the link there too? Of 19,441 such links, 13,155 are. Of the rest, 1,727 start from a release synset with no hypernym at all: ampér has elektromagnetická jednotka above it in the PDT copy and nothing in the release.

parents = {h.id for h in child.hypernyms()}
for target in row.nas.hypernyms:
    up = rows.get(target)
    if up and up.ili and up.wncze:
        both += 1
        kept += up.wncze in parents
        orphans += not parents

How much to trust this

This page was written by an AI from the source file. Treat the code as the source of truth:

  • Every code claim carries a file:line reference: open it.
  • The numbers come from one run, at commit df27b6f, against wncze:2.2; they will move with the next release.
  • Look hypernyms up through wn.Wordnet(lexicon="wncze:2.2"), as the script does. wn.synset() uses all lexicons and can show an inferred, empty hypernym for a synset such as ampér.
  • "Carried" is a string match: a definition reworded in the release counts as not carried.
  • The quiz answers follow from the code; where one disagrees, the code wins.

Glossary

PDT copyCzech WordNet 1.9 PDT, the wordnet the annotators chose senses from; ids are WordNet 1.5 offsets or new ids such as NAS-450034833.
releaseCzech WordNet 2.2, wncze:2.2; ids are WordNet 2.0 offsets.
ILIan Interlingual Index id such as i33221, one per concept across wordnets.
CILI confidencehow sure the 1.5-to-ILI map is, 0 to 1; below 1 the link is often wrong.
edit stampwho changed a PDT synset and when, e.g. bejce9am 2006/03/14.
tagsannotated words in PDT carrying that synset.
