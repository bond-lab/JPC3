Background

The Prague Dependency Treebank (PDT) is sense-annotated: words are tagged with wordnet synsets. But those tags were made against Princeton WordNet 1.5, an inventory decades out of date. Synsets have since been split, merged, renumbered, and dropped. Project 3 re-anchors the tags to the current Czech wordnet — and, more interesting, characterises the residue that will not carry over.

The feared route is a chain of version maps (1.5 → 1.6 → … → 3.0). It is unnecessary. The CILI project keeps historical tables under older-wn-mappings/, including ili-map-pwn15.tab, which maps a 1.5 offset straight to an ILI. And the Czech wordnet is keyed to ILIs.

Three columns. The 1.5 table has ili, offset-pos, and a confidence flag — unlike the two-column 3.1 table. Parse all three; the confidence column is itself worth reporting on.

Intuition

Each PDT tag is a 1.5 offset. Look it up in the table to get an ILI, then ask the Czech wordnet for the synset with that ILI. Every tag lands in one of three buckets:

PDT tag (1.5)ILICzech synsetBucket
00002403-ai1schopný mapped
00002738-ai2neschopný mapped
99999999-n—— no-ili not in the 1.5 table at all

A fourth outcome, missing-synset, is an ILI the table knows but the Czech wordnet has no synset for. Across the whole 1.5 table, about 26,000 of its ~87,000 ILIs resolve to a Czech synset — so the bridge reaches a large share of the inventory before you touch PDT. The unmapped rest is the bug list for the maintainers.
