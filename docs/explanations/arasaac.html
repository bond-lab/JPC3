Background

ARASAAC is a large open set of pictograms used in augmentative and alternative communication (AAC) — for people who cannot speak, a board of pictures stands in for words. Project 4 links those pictures to Czech wordnet synsets so that each concept has an image, and, through the wordnet, the same picture can serve every language.

The lucky part: ARASAAC pictograms already carry a WordNet 3.1 synset id in their metadata, plus Czech keywords and a sex flag for gendered variants. So there is nothing to guess — only a version gap to cross. That gap is the same one project 5 crosses: a 3.1 offset is not an ILI, but the CILI table turns it into one, and the Czech wordnet is keyed to ILIs.

Why precision matters here. A wrong synset tag means the wrong picture, and a child who cannot speak is handed the wrong word. Of the six projects this is the one where a lexical slip reaches a real user fastest.

Intuition

Search ARASAAC for a Czech word, read each pictogram's synset tag, convert it to an ILI, and look up the Czech synset. A real run for pes "dog":

PictogramTag (3.1)ILICzech synset
720202086723-ni46360 pes, psovitá šelma matched
251702086723-ni46360 pes, psovitá šelma matched

Two different drawings of a dog resolve to the same Czech synset — exactly what you want. Each line also carries the image URL, so the next step (attach it, check it is a fair picture of that sense) can start at once. A tag that yields no Czech synset prints MISSING: a concept the Czech wordnet lacks, or a wrong tag to report back to ARASAAC.
