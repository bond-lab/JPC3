Background

Some synsets will never have a drawn pictogram and do not need one. Colour terms are the clear case: ARASAAC has a handful, but the wordnet has far more — kaštanová "chestnut", spálená oranžová "burnt orange", and on. For a colour the ideal picture is simply the colour.

The xkcd colour survey asked thousands of people to name colours and settled on 949 names with hex values. matplotlib ships that table offline as XKCD_COLORS. So a colour synset's pictogram can be generated: look up the name, paint a square, label it.

Say it is generated. A swatch is not a drawing. In the report's data statement, mark these images as generated from the xkcd table, and note the limits: the names are crowd-sourced English, so the Czech match still needs checking, and a flat square suits a colour but not, say, a shade of a feeling.

Bridge the result to the wordnet the way the other project-4 script does: match the xkcd name to the English colour lemma, follow the ILI to the Czech synset, attach the generated image. An unknown name returns None rather than a blank image, so the caller can tell "no such colour" from "done".

Code

1 · swatch()

Look the name up (lower-cased, with the xkcd: prefix matplotlib uses), bail out with None if it is unknown, otherwise draw a full-figure rectangle, add the label, save, and close the figure so a loop over hundreds of colours does not leak memory.

hexv = XKCD_COLORS.get(f"xkcd:{name.lower()}")
if not hexv:
    return None
fig, ax = plt.subplots(figsize=(2, 2))
ax.set_axis_off()
ax.add_patch(plt.Rectangle((0, 0), 1, 1, color=hexv))
