Background

Project 6 asks a language model to flag suspicious synsets — a lemma in the wrong sense, a missing synonym, a spurious member — with a rationale, and then measures how good those flags are. A model will happily flag things; the question is whether it is right.

Two decisions make the answers measurable, and this script makes both. First, ground the model: instead of letting it free-associate about a Czech word, hand it evidence for the same concept — the English lemmas and gloss reached through the shared ILI in omw-en, and, where the Wikidata run found one, Wikidata's Czech label. Second, fix the output shape: a closed verdict, a closed problem type, one sentence of rationale, a confidence. Prose answers cannot be scored; a schema can.

No API call here. This is the half you can run offline and read with your own eyes before spending a token. The call itself — and the validation of what comes back against a human gold standard — is the project.

Intuition

One record per synset, with everything the model may cite. From a real run:

{"synset": "ntumc-cs-02783161-n", "ili": "i50413",
 "czech_lemmas": ["propisovací tužka", "propiska", "kuličkové pero"],
 "english_lemmas": ["ballpoint", "ballpoint pen", "ballpen", "Biro"],
 "gloss": "a pen that has a small metal ball as the point of transfer of ink to paper",
 "wikidata_cs": null}

And the answer the model must return, the same shape every time:

{"synset": "...", "verdict": "ok | suspect",
 "problem": "wrong-sense | missing-lemma | spurious-lemma | bad-gloss | none",
 "rationale": "one sentence, citing the evidence", "confidence": 0.0}

With the shape fixed, the evaluation is ordinary: a human labels a blind sample with the same schema, and you report precision and recall for suspect, a confusion matrix over problem, and whether confidence tracks correctness. The cleanest experiment is an ablation — run it with and without the Wikidata field and see whether grounding cuts false flags.

For one Czech synset, follow its ILI to the English synset and collect the lemmas and the first gloss; add the Wikidata label if any. The ILI is the only join key — no string matching.
