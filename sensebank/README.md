# Project 3 — Merging the PDT wordnet sense tags

The Prague Dependency Treebank is sense-annotated against **PWN 1.5**-era Czech
wordnet synsets. Re-anchor those tags to the current synset inventory, **use
them to add corpus frequencies** to the Czech wordnet — once a tag maps, every
tagged token in the treebank is a sense count — and characterise the
**residue**: the tags that don't carry over.

## The good news: a direct 1.5 → ILI map

CILI ships historical maps under
[`older-wn-mappings/`](https://github.com/globalwordnet/cili/tree/master/older-wn-mappings),
including `ili-map-pwn15.tab`. So the hop you feared (chaining 1.5→1.6→…→3.0)
is unnecessary: map the PDT synset offset straight to an ILI, then to Czech.

The file has **three** tab-separated columns — `ili`, `offset-pos`,
`confidence` — so parse all three (the confidence flag is itself worth
reporting on in the error analysis):

The bridge is in [`pdt_to_czech.py`](pdt_to_czech.py) — it caches the 1.5 map
beside itself and maps offset → ILI → Czech synset:

```bash
uv run pdt_to_czech.py 00002403-a 00007846-n     # offsets as arguments
uv run pdt_to_czech.py < tags.txt                 # one PDT offset per line
```

Each line comes back as `offset  ili  lemmas | MISSING-SYNSET | NO-ILI`, with a
count of each at the end — the residue you will categorise.

Sanity check: of the ~87k distinct ILIs in the 1.5 map, **26 363** resolve to a
synset that exists in the Czech wordnet — so the bridge reaches a large share of
the inventory before you even look at PDT.

## What to actually build

1. Read the PDT sense tags (your input data). Each is an old synset id / offset.
2. Map offset → ILI → current Czech synset with the helper above.
3. Classify every tag:
   - **mapped** — one current synset, done.
   - **split / merged** — the old synset corresponds to several current ones, or
     several old ones collapse into one (use the confidence column and the
     English gloss to decide).
   - **renumbered** — maps via ILI but the offset changed.
   - **deleted / missing** — no ILI, or the ILI has no Czech synset.
4. Count **sense frequencies**: for every mapped tag, tally the tagged tokens
   per current synset (and per lemma within it), and add the counts to the
   Czech wordnet release as sense frequencies, naming the corpus and its
   version in the data statement.
5. Hand-categorise ~500 of the **unmapped residue** — that taxonomy is the
   other deliverable. Compare against the structural-mapping approach of
   Daudé et al.

## Feedback

- The mapping table (PWN 1.5 offset → ILI → current synset) and the
  categorised residue go to the **PDT maintainers**.
- The sense frequencies go into the **Czech wordnet** release.
- Stretch: add the synsets the residue shows to be **missing** to the Czech
  wordnet, so the next mapping run has nothing left to map.
